Sprawdza status zamowienia klienta.

Uzyj, gdy klient pyta o status, wysylke lub dostawe konkretnego zamowienia.
Wymaga numeru zamowienia podanego przez klienta.
Numer telefonu klienta jest dodawany automatycznie przez system i nie jest parametrem do podania.

Zwraca: status, przewidywana data dostawy, przewoznik (jesli dostepne).
Nie uzywaj do zmian, anulowania ani zwrotow zamowien.
